⚙️ Firebase (Firestore) 연동 가이드

이 웹앱은 Firebase JS SDK(CDN 방식)를 탑재하고 있습니다. 여러분의 프로젝트 설정값을 넣으면 전 세계 어디서나 실시간 클라우드 저장이 활성화됩니다!

(1) Firebase 콘솔에서 새 프로젝트 생성하기:
1. 웹 브라우저로 console.firebase.google.com에 접속하여 Google 계정으로 로그인합니다.
2. '프로젝트 추가' 버튼을 누르고 프로젝트 이름(예: data-detective-app)을 입력한 뒤 단계를 진행하여 생성합니다.
(2) Firestore Database를 테스트 모드로 생성하고 컬렉션 구조 확인하기:
1. 좌측 메뉴에서 빌드 > Firestore Database를 선택하고 '데이터베이스 만들기'를 클릭합니다.
2. 보안 규칙 단계에서 '테스트 모드에서 시작'(누구나 읽기/쓰기 허용)을 선택하고 완료합니다.
3. 컬렉션 구조: 본 웹앱은 detective_reports 컬렉션에 보고서(사건명, 날짜, 데이터, 통계, 메모)를 JSON 문서 형태로 자동 생성 및 저장합니다.
(3) "웹 앱 추가"로 앱 등록 후 firebaseConfig 얻기 및 코드에 붙여넣는 위치:
1. Firebase 프로젝트 홈 화면 중앙의 웹 아이콘(</>)을 클릭하여 웹 앱을 등록합니다.
2. 화면에 나타나는 const firebaseConfig = { ... } 코드 블록을 복사합니다.
3. app.js 파일의 가장 상단에 위치한 아래 객체에 실제 발급받은 키 값을 대입해주시면 즉시 클라우드 Firestore와 자동 연동됩니다:
const firebaseConfig = { apiKey: "여기에_API_KEY", authDomain: "여기에_AUTH_DOMAIN", projectId: "여기에_PROJECT_ID", storageBucket: "여기에_STORAGE_BUCKET", messagingSenderId: "여기에_SENDER_ID", appId: "여기에_APP_ID" };

✏️ 단서 행 데이터 직접 수정

선택한 단서 행의 값들을 확인하고 수정한 뒤 [저장하기]를 누르면 즉시 그래프와 분석에 반영됩니다.
